# UWC Student Management System

A Java console application designed to manage university student records, academic performance, and outstanding fees.

This project is being developed incrementally as part of my journey to strengthen my Java Object-Oriented Programming (OOP) and problem-solving skills.

## Project Goals

- Practise classes, objects, constructors, and encapsulation.
- Manage student objects using an `ArrayList`.
- Implement searching, updating, and deleting records.
- Apply getters and setters to access and modify student information.
- Generate academic and financial reports.
- Practise input validation and menu-driven console applications.
- Learn Git and GitHub through consistent version control.

## How to Run

The application is currently under development.

Once the main class is implemented, compile and run the application using:

```bash
javac Student.java StudentManagement.java
java StudentManagement
```

Run these commands from the directory containing the Java source files.
